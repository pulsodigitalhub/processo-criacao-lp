# Índice dos playbooks

Status: vigente desde 29/10/2026. Origem: LP do Dr. Breno Lima e as LPs do Pedro, Rodrigo e Matheus.

`01-pacote-de-entrega.md`, define o que a Pulso entrega por cliente de saúde.

`02-secoes-da-lp.md`, define a ordem e os requisitos das seções da LP geral.

`03-componentes-obrigatorios.md`, define os componentes de LPs de anúncio.

`04-variacoes.md`, define como gerar e priorizar variações de campanha.

`05-site-institucional.md`, define o institucional dentro do domínio da LP.

`06-publicacao.md`, define o processo de deploy e domínio.

`07-fechamento.md`, define os registros, integrações e validações após publicar.

O processo, `AGENTS.md` e `docs/`, diz como fazer uma LP. Os playbooks dizem o que a casa entrega e os padrões repetidos. Regra que não pode falhar vira checagem no gate.
